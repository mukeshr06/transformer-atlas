Individual operations expand to fill the visual stage. 2D preserves the paper diagram. 3D displays live coordinates and numerical transformations. Reading the paper through the diagram

The journey begins with context, the sequential bottleneck in recurrent models, and the motivation for attention. It then follows the architecture from embeddings to predictions, learning, generation, and the paper’s training choices and reported results. Each chapter explains why the operation is needed, how it works, and what its result means.

A small live numerical lens

The original base architecture uses six blocks in each stack, 512 features, eight heads and 2,048 feed-forward features. This browser model uses one or two blocks, four features, two heads and eight hidden features so that all arithmetic is inspectable. The starting task copies “rain feeds rivers”. Your text accepts up to six word or punctuation tokens per side and initializes new vocabulary entries as needed. It starts untrained; its outputs are predictions, not reliable language understanding. N× marks the repeated structure; each repeated block has distinct parameters.

The example uses word-level tokens, sinusoidal positions and post-norm residual blocks. Its seeded weights are untrained. Every activation, probability, loss and first-order gradient is calculated locally. Training uses clipped SGD; the paper uses Adam and a warmup schedule. This miniature omits dropout and label smoothing and uses untied embeddings/output weights. It is an explanatory model, not a reproduction of the paper’s trained system or benchmark results.

Going deeper

The scrolling journey includes every forward operation and all 70 supplied diagram concepts, rebuilt with frontend text, shapes, matrices, network connections and vector geometry. Atlas also exposes every backward calculation. Opening an internal step inserts it into the scrolling journey while preserving the same architecture. All values exposes full tensors; learned values can be edited. Training changes weights; generation grows a prefix with fixed weights.
